# 스킬투머니 (SkillToMoney) 원데이 클래스

배운 기술이 돈이 되는 실전 원데이 클래스 웹 애플리케이션입니다.

---

## 📌 주요 구현 내용 및 개발 히스토리

### 1. 강좌 데이터 모듈 분리 (`data/courses.js`)
강좌 데이터를 독립적인 파일(`data/courses.js`)로 분리하였으며, 각 강좌는 `id`, `name`, `price`, `seat`, `booked`, `date`, `tags` 스키마를 가집니다.

| 강좌명 | 수강료 | 정원 (`seat`) | 예약 (`booked`) | 남은 좌석 (`seat - booked`) | 강의 일정 (`date`) | 태그 (`tags`) | 초기 상태 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- | :---: |
| **AI 자동화** | 35,000원 | 8명 | 8명 | **0석** / 정원 8명 | 2026-11-07 | 초보 환영, 2시간 | **마감** (예약 마감) |
| **숏폼 편집** | 45,000원 | 6명 | 2명 | **4석** / 정원 6명 | 2026-11-14 | 캡컷, 3시간 | **예약 가능** |
| **엑셀 실무** | 30,000원 | 10명 | 7명 | **3석** / 정원 10명 | 2026-11-21 | 함수 실습 | **예약 가능** |
| **스마트스토어** | 40,000원 | 6명 | 5명 | **1석** / 정원 6명 | 2026-11-28 | 상세페이지, 창업 준비 | **마감 임박** (빨간색) |

---

### 2. 잔여 좌석 표시 및 카드 UI
- **문구 형식**: 각 강좌 카드에 **`남은 좌석 ○석 / 정원 ○명`** 표기
- **계산 로직**: `const remaining = course.seat - course.booked;`
- **프로그레스 바**: 현재 예약 비율(`(course.booked / course.seat) * 100%`)을 시각적으로 나타내는 바 제공
- **반응형 4열 그리드**: 4개 강좌가 모바일(1열), 태블릿(2열), 데스크톱(4열)에서 최적으로 표시되도록 레이아웃 구성

---

### 3. 좌석 상태별 인터랙션 및 제어 규칙

1. **남은 좌석이 0석인 경우 (마감)**
   - **배지 표시**: `마감` (회색 배지)
   - **버튼 UI**: 버튼 문구가 `예약 마감`으로 변경
   - **동작 제어**: `disabled` 속성 및 `cursor-not-allowed` 적용으로 클릭 불가 처리
   - *해당 강좌: AI 자동화*

2. **남은 좌석이 1~2석인 경우 (마감 임박)**
   - **배지 표시**: 빨간색 텍스트 및 배경, 펄스 애니메이션이 적용된 **`마감 임박`** 배지 표시
   - **프로그레스 바**: 빨간색 하이라이트 적용으로 긴박감 연출
   - **버튼 UI**: `예약하기` 버튼 유지 및 정상 예약 가능
   - *해당 강좌: 스마트스토어 (남은 좌석 1석)*

3. **남은 좌석이 3석 이상인 경우 (예약 가능)**
   - **배지 표시**: 초록색 `예약 가능` 배지 표시
   - **버튼 UI**: `예약하기` 골드 그라데이션 버튼 활성화
   - *해당 강좌: 숏폼 편집 (4석), 엑셀 실무 (3석)*

---

### 4. 예약 신청 모달 폼 및 서버 사이드 API 보안 연동 (`app/api/reserve`)
- **신청 창 오픈**: 각 카드의 `[예약하기]` 버튼 클릭 시 해당 강좌의 예약 신청 모달 오픈
- **자동 기입 필드**:
  - `강좌 이름`: 선택한 카드의 강좌명이 자동으로 채워짐 (`readOnly`)
  - `날짜`: 선택한 카드의 강의 일정(`date`)이 자동으로 채워짐 (`readOnly`)
- **사용자 입력 검증 및 안내 문구**:
  - `이름`이 비어 있으면 전송하지 않고 `"이름을 입력해 주세요."` 경고 안내 문구를 모달 내에 표시합니다.
  - `신청 인원`이 남은 좌석보다 많으면 전송하지 않고 `"신청 인원(○명)이 남은 자리(○석)보다 많습니다. 인원을 다시 확인해 주세요."` 안내 문구를 표시합니다.
- **보안 및 서버 측 처리 (`app/api/reserve/route.ts`)**:
  - **시트 주소 비노출**: 브라우저는 오직 내부 서버 엔드포인트인 `/api/reserve`로만 요청하여 구글 시트 웹 앱 URL(`SHEET_URL`)이 사용자 브라우저에 일절 노출되지 않습니다.
  - **서버 측 결제 금액 계산**: 클라이언트가 보낸 금액이 아니라, 서버가 `data/courses.js`의 공식 수강료(`price`)와 인원 수(`people`)를 곱해 `total`을 안전하게 계산하여 구글 시트로 전송합니다.
  - **전송 완료 후 반영**: 구글 시트 "예약" 탭에 한 행이 기록되며, 성공 응답 시 화면 잔여 좌석 즉시 갱신 및 완료 토스트 알림이 뜹니다.
- **모달 버튼 및 성공 메시지**:
  - `[닫기]`: 모달 창 닫기
  - `[신청]`: 서버 API로 예약 접수 요청 (보내는 동안 **`"저장 중..."`**으로 버튼 텍스트 변경 및 비활성화)
  - **성공 피드백**: 성공 시 우측 하단 토스트에 **`"예약 신청이 완료되었습니다"`**를 선명하게 표시합니다.

---

### 5. 예약 가능한 강좌 필터링 기능
- **체크 상자**: 강좌 목록 상단에 **`예약 가능한 강좌만 보기`** 체크 상자 제공
- **필터링 조건**:
  - 체크 시: 남은 자리가 있는 강좌(`course.seat - course.booked > 0`)만 표시 (마감된 AI 자동화 제외 3개 강좌 표시)
  - 체크 해제 시: 마감 강좌를 포함한 전체 강좌(4개) 표시
- **표시 카운트**: 현재 표시 중인 강좌 개수(`filteredCourses.length`) 및 필터 상태 안내 뱃지 제공

## 🛠 기술 스택

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript, React 19
- **Data Source**: `data/courses.js`
- **Styling**: Tailwind CSS v4, 네이비 & 골드 프리미엄 다크 테마

